# AIpenetrationRate · 美国企业 AI 渗透率双周看板

数据源：U.S. Census Bureau **BTOS**（Business Trends and Outlook Survey）

- 主指标：过去两周内任一业务职能使用 AI 的美国企业占比（企业数加权）
- 频率：双周更新（BTOS 隔周四美东发布，本仓库随发布次日自动刷新）
- 口径提示：2025-11 措辞切换（"任一职能使用"），序列自该期起算，与此前老口径不可拼接

在线页面：GitHub Pages（本仓库 index.html）

数据下载：https://www.census.gov/hfp/btos/data_downloads
